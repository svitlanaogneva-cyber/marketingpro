# Заявки з сайту → Google Sheets

Сайт (Vercel, `POST /api/lead`) перевіряє й збагачує заявку та передає її в Apps Script, який живе
всередині таблиці й дописує рядок. Сервісні акаунти, Google Cloud і шарінг таблиці не потрібні.

```
форма → /api/lead (перевірка Origin, honeypot, ліміт, очищення, UTM/пристрій/гео)
      → Apps Script Web App (перевірка секрету, замок, дедуплікація за ID) → аркуш «Заявки»
```

## Одноразове налаштування (робить власник таблиці)

1. Таблиця → **Розширення → Apps Script** → видаліть усе в `Код.gs` і вставте вміст `Code.gs` з цієї теки → **Зберегти**.
2. Угорі виберіть функцію **`setup`** → **Запустити**. Google попросить дозволи: це власний скрипт, тому попередження
   «додаток не перевірено» нормальне: **Додатково → Перейти на сторінку… (небезпечно) → Дозволити**
   (скрипт має `@OnlyCurrentDoc`, тобто бачить лише цю таблицю).
3. У таблиці зʼявляться аркуші **«Заявки»** та **«Аналітика»** і вікно з **секретом** — скопіюйте його.
4. **Ввести в дію → Нове розгортання → Веб-застосунок**: «Виконувати від імені» — *Я*, «Хто має доступ» — *Усі*
   → **Ввести в дію** → скопіюйте URL, що закінчується на `/exec`.
5. Vercel → Project → **Settings → Environment Variables** (Production і Preview):
   - `LEAD_WEBHOOK_URL` = URL з кроку 4
   - `LEAD_WEBHOOK_SECRET` = секрет з кроку 3

   → **Redeploy**.
6. Перевірка: у таблиці меню **marketingpro → Додати тестову заявку**, потім відправте форму на сайті.

> Секрет зберігається у **Властивостях скрипта** (⚙ Налаштування проєкту → Script properties → `LEAD_SECRET`)
> і в Vercel. У код, таблицю й git він не потрапляє. Замінити: змініть значення в обох місцях.

## Оновлення скрипта

Змінили `Code.gs` → вставте новий код → **Ввести в дію → Керувати розгортаннями → ✏️ → Версія: Нова → Ввести в дію**.
URL при цьому не змінюється. Після зміни `COLUMNS` запустіть **marketingpro → Налаштувати / оновити оформлення**
(дані заявок не чіпає; але якщо додали колонку посередині, існуючі рядки треба зсунути вручну).

## Що зберігається

**Видимі колонки:** дата і час (Київ), статус (випадаючий список: Новий → Зв’язались → В роботі → Клієнт / Відмова / Спам),
тип (Консультація / Академія), курс (для академії), імʼя, телефон/Telegram (клікабельні), Instagram/сайт (клікабельний),
ніша, заповненість (Повна / Часткова / Лише контакт), джерело, кампанія, коментар менеджера.

**Технічні (згорнуті, «+» над літерами колонок):** ID заявки, день / тиждень / місяць (для групування),
сторінка з формою, UTM medium/content/term, click ID (fbclid/gclid/ttclid), реферер, перша сторінка візиту,
які кейси дивився, скільки сторінок і часу до заявки, перший чи повторний візит, країна/регіон/місто (з Vercel),
пристрій і браузер (з позначкою «Instagram/Facebook/Telegram-застосунок»), мова, часовий пояс, екран,
Meta `_fbp`/`_fbc` (знадобляться для Pixel/Conversions API), хеш IP (щоб бачити спам з однієї адреси; сам IP не зберігається),
User-Agent.

**Джерело** визначається так: `utm_source` → рекламний клік (fbclid → «facebook / instagram (реклама)», gclid → google,
ttclid → tiktok) → домен реферера → застосунок (Instagram/Facebook/Telegram) → `direct`.
UTM-мітки запамʼятовуються на весь візит: людина могла прийти з реклами, походити сайтом і залишити заявку на іншій сторінці.

## Зручність роботи

- Фільтр на всіх колонках (шапка), перші 2 колонки (дата, статус) і шапка закріплені.
- **marketingpro → Нові зверху** — один клік сортує за датою від нових до старих (автоматично не сортуємо, щоб рядки не «тікали»).
- Аркуш **«Аналітика»** (формули, оновлюється сам): заявки сьогодні / 7 / 30 днів, нові без обробки, клієнти й конверсія,
  розрізи за джерелом, кампанією, курсом, сторінкою, типом і по днях.
- Статуси підсвічуються кольором, «Відмова» і «Спам» приглушуються.

## Надійність і безпека

- Секрет порівнюється без раннього виходу; без нього скрипт відповідає `forbidden`.
- Запис під `LockService` — одночасні заявки не потрапляють в один рядок.
- ID заявки генерується в браузері один раз на форму: повторна відправка (подвійний клік, ретрай) не створює дубль.
- Усі значення пишуться в клітинки з форматом «звичайний текст»: `=формули` не виконуються, телефон не стає числом.
- Якщо Sheets недоступний — сайт двічі пробує, показує людині повідомлення з Telegram-запасом,
  а повна заявка лишається в логах Vercel (`[lead:FAILED]`), її можна внести вручну.
- Сайт приймає POST лише з власного Origin, відсікає ботів через honeypot, обмежує частоту й розмір запиту.
- Персональні дані (імʼя, контакт) потрапляють у вашу таблицю: доступ до неї визначаєте ви.
  Якщо на сайті є відвідувачі з ЄС, додайте на сайт політику конфіденційності.

## Локальна перевірка без Google

`LEAD_WEBHOOK_URL=http://localhost:4010/exec LEAD_WEBHOOK_SECRET=test npm run dev` + будь-який мок-сервер,
що приймає `POST {secret, lead}` і повертає `{"ok":true}` (з редіректом 302, як справжній Apps Script).
